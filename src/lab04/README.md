# Лабораторная работа 4 

## Задание А
Реализует функции для работы с файлами: чтение текстового файла целиком в заданной кодировке (`read_text`, по умолчанию `utf-8`) и запись данных в CSV-файл с разделителем `,` (`write_csv`). Перед записью проверяет, что все строки и заголовок имеют одинаковую длину, иначе вызывает `ValueError`. Если файл не найден или кодировка не подходит, исключение передаётся дальше без перехвата. При необходимости автоматически создаёт родительские папки. Файл расположен в `src/lab04/io_txt_csv.py`.

![A задание](../../images/lab04/img%20A.png)

## Задание В

Скрипт читает текстовый файл, нормализует и разбивает текст на слова с помощью `src/lib/text.py`, подсчитывает частоты слов и сохраняет полный отчёт в CSV с колонками word,count, отсортированный по частоте и алфавиту. В консоль выводит общее и уникальное количество слов, а также топ-5 самых частых слов. Пути к файлам и кодировка задаются константами в начале скрипта. Если входной файл не найден, выводится сообщение об ошибке. Файл расположен в `src/lab04/text_report.py`.

![B задание](../../images/lab04/img%20B.png)

## Краевые случаи

- **Пустой входной файл:** `report.csv` содержит только заголовок `word,count`, без строк с данными. В консоли выводятся `Всего слов: 0`, `Уникальных слов: 0` и `Топ-5:` без списка слов.

- **Файл не найден:** скрипт выводит сообщение `Ошибка: файл не найден: <путь>` и завершает работу.

- **Кодировки:** по умолчанию файлы читаются и записываются в `UTF-8`. Чтобы использовать другую кодировку, нужно изменить константу `ENCODING` в начале `text_report.py`, например, на `"cp1251"`.

- **Смена выходного и/или выходного файла:** пути к входному и выходному файлам задаются константами `INPUT_PATH` и `OUTPUT_PATH` в начале `text_report.py`. Чтобы обработать другой файл, нужно изменить их значения в коде.

## Запуск `text_report.py`

```python
python -m src.lab04.text_report 
```
Заупск из корня репозитория, там где лежит папка `src` с помощью `-m`
